# SRE Student Learning Path

This roadmap is for a student who wants to become a Site Reliability Engineer (SRE), using the best free and student-friendly resources available through GitHub Education.

## Goal

Learn the core SRE skills:
- Linux and shell scripting
- Git and GitHub workflows
- Cloud infrastructure (AWS and Azure)
- Containers and Kubernetes
- CI/CD pipelines
- Monitoring and observability
- Incident response and reliability engineering

## Site Reliability Engineer Roadmap 2026 (Simplilearn)

SRE Learning Path (Steps 1-8)

### Step 1: Linux & Networking
- Foundation: Linux operating systems, networking protocols, IP addressing

### Step 2: Programming & Scripting
- Languages: Go, Python — essential for automation and infrastructure scripts

### Step 3: Cloud & Infrastructure
- Platforms: AWS, cloud architecture, infrastructure fundamentals

### Step 4: Containers & Orchestration
- Technologies: Docker, container management, orchestration principles

### Step 5: CI/CD Pipelines
- Continuous Integration/Deployment, automated testing, deployment automation

### Step 6: Cloud & Infrastructure (Advanced)
- Includes: Kubernetes (K8s), advanced orchestration
- Tools shown: Helm, other cloud-native technologies

### Step 7: Monitoring & Observability
- System monitoring, logging, distributed tracing, metrics collection

### Step 8: Incident Management & Security
- Incident response, security practices, risk management

### Final Level: Projects & Certifications
- Capstone projects demonstrating SRE skills
- Professional certifications to validate expertise

## Best Resource Order

### Phase 1: Foundations and GitHub workflows
Start here.

1. GitHub Education Student Developer Pack
   - https://education.github.com/pack
   - Why: Unlocks student benefits and free learning resources.

2. GitHub Skills / GitHub Learning Lab
   - https://skills.github.com/
   - Why: Hands-on GitHub practice, badges, and real workflow experience.

3. GitHub Foundations (when available through the student pack)
   - Why: Good beginner certification for GitHub fundamentals and developer workflows.

4. GitHub Copilot learning / AI-assisted workflow practice
   - Why: Modern engineering roles increasingly use AI-assisted coding and automation.

### Phase 2: Linux, scripting, and cloud basics
This is the SRE foundation.

5. Educative (via GitHub Student access)
   - https://www.educative.io/github-students
   - Recommended topics:
     - Linux basics
     - Bash scripting
     - Networking
     - Docker
     - Kubernetes
     - DevOps and SRE fundamentals

6. Azure for Students
   - https://azure.microsoft.com/free/students/
   - Why: Excellent cloud learning path for SRE students.
   - Recommended topics:
     - Virtual machines
     - Networking
     - Identity and access
     - Monitoring
     - Compute and deployment

7. AWS Educate / free AWS student resources
   - https://aws.amazon.com/education/awseducate/
   - Why: AWS is widely used in production and an important SRE platform to understand.
   - Recommended topics:
     - EC2
     - VPC and networking
     - IAM
     - Load balancing
     - S3 and storage basics
     - CloudWatch
     - IAM and security fundamentals

### Phase 3: Data, systems, and operational knowledge
SREs need to understand systems and failure patterns.

8. MongoDB University
   - https://www.mongodb.com/university
   - Why: Strong database and operational knowledge for backend and systems work.

9. DataCamp (if available through student benefits)
   - Why: Good for Python, SQL, metrics, and data analysis.

### Phase 4: Reliability engineering and production thinking
This is the real SRE layer.

10. Kubernetes and containers
    - Learn:
      - pods
      - deployments
      - services
      - configmaps and secrets
      - health checks
      - rollouts and rollbacks

11. Monitoring and observability
    - Learn:
      - metrics
      - logs
      - traces
      - dashboards
      - alerts
    - Tools:
      - Prometheus
      - Grafana
      - OpenTelemetry
      - Azure Monitor
      - AWS CloudWatch
      - Loki

12. Incident response and resilience
    - Learn:
      - SLIs
      - SLOs
      - runbooks
      - postmortems
      - failure domains
      - recovery strategies

## Capstone Project Idea

Build a small production-like system that demonstrates SRE skills:

Project: Reliable Web Service on AWS and Azure
- GitHub repo
- CI/CD workflow with GitHub Actions
- Dockerized app
- Deployment to AWS and Azure
- Monitoring and alerts
- Health checks
- Runbook documentation
- Incident report template

This project is more valuable than learning in isolation because it shows you can operate software in real environments.

## Final Advice

For an SRE student, the highest-value combination is:
- GitHub basics + GitHub Actions
- Linux + scripting
- Cloud fundamentals (AWS + Azure)
- Docker + Kubernetes
- Monitoring and incident response

This combination gives you both the theory and the practical experience needed for an entry-level SRE role.
